# Launch checklist

## Content approval

- [ ] Confirm church email address.
- [ ] Confirm rector and current vestry list.
- [ ] Confirm Church School remains at 9:00 AM.
- [ ] Confirm parking, entrance, and accessible drop-off directions.
- [ ] Confirm all history language and dates.
- [ ] Confirm whether any National Register nomination/listing language may be used.
- [ ] Confirm campaign name, scope, goal, raised amount, giving levels, and contacts.
- [ ] Replace every “Needs church confirmation” or “Verify before public launch” note.
- [ ] Review privacy policy and pastoral-care emergency language.

## Media

- [ ] Secure permission for every photograph and story.
- [ ] Convert and review selected HEIC files.
- [ ] Add people, worship, fellowship, archive, transportation, and campaign photography.
- [ ] Verify every meaningful image has accurate alt text.
- [ ] Add captions/transcripts for published video and audio.

## Forms and backend

- [ ] Create production Supabase project.
- [ ] Apply `database/schema.sql`.
- [ ] Configure public URL and anonymous key.
- [ ] Add CAPTCHA and rate limiting through an Edge Function.
- [ ] Test all twelve form types and all UI states.
- [ ] Configure redacted email notifications.
- [ ] Define retention and deletion policy.
- [ ] Add Supabase Auth and role-based admin access.
- [ ] Verify CSV export.

## Technical QA

- [ ] Test every internal and external link.
- [ ] Check desktop, tablet, and common mobile sizes.
- [ ] Test keyboard navigation and visible focus.
- [ ] Test screen reader landmarks, menu, forms, and errors.
- [ ] Test reduced motion.
- [ ] Check browser console and network failures.
- [ ] Run Lighthouse for performance, accessibility, SEO, and best practices.
- [ ] Validate schema.org output, sitemap, robots, canonical URLs, and social cards.
- [ ] Test GitHub Pages base paths from the production URL.
- [ ] Confirm no confidential admin/member data is publicly exposed.

## Launch

- [ ] Take a final backup.
- [ ] Publish and smoke-test production.
- [ ] Submit sitemap to Google Search Console and Bing Webmaster Tools.
- [ ] Document staff ownership for events, campaign totals, forms, and media.
- [ ] Schedule quarterly content and accessibility reviews.
