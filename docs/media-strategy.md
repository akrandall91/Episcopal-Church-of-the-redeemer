# Media strategy

## Narrative sequence

The homepage follows “The Walk In”:

1. Exterior and arrival
2. Doors and sanctuary
3. Worship and sacred detail
4. People, families, and fellowship
5. Historic memory
6. Restoration and future

The current collection covers exterior architecture and sanctuary. High-priority future photography is people-centered: greeters, worship, choir, Communion details, families, elders, students, fellowship, service, archival material, and renovation needs.

## Performance and accessibility

- Export WebP and AVIF where practical; keep JPEG fallbacks when needed.
- Hero target: 1600–2200 px wide and ideally below 350 KB.
- Content target: 800–1400 px wide and usually below 200 KB.
- Include intrinsic dimensions to reduce layout shift.
- Lazy-load below-the-fold images.
- Alt text should describe meaningful visual information, not repeat nearby captions.
- Decorative textures should use empty alt text or CSS backgrounds.
- Video needs a poster image, captions, and transcript placeholder.
