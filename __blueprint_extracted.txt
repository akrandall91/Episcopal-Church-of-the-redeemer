SECTION 01   ?   Episcopal Church of The Redeemer

Strategic Foundation & Positioning
Who Redeemer is, who it serves, and how the site must work for them



1.1  Executive Summary

The Episcopal Church of The Redeemer is one of Greensboro&apos;s most historically significant institutions — a 115-year-old African-American Episcopal parish that served as a Civil Rights organizing hub, launched an entire diocese&apos;s mission presence for Black Episcopalians, and continues to anchor its community today. Its current website does not reflect that weight. This blueprint redesigns it from the ground up: historically grounded, conversion-optimized, SEO-structured, and built to scale.

All have a place at Redeemer.

6.5  Payment Processor Recommendation

??  Recommended: Tithe.ly or Stripe

Tithe.ly: Purpose-built for churches. Supports recurring giving, text-to-give, mobile app, CRM sync.

  ? tithely.com — integrates with most church CMS platforms

Stripe: Lower fees (2.2% + $0.30), more control, custom UI, developer-friendly.

  ? stripe.com — requires more setup but more flexible

PayPal: Easiest to set up, widely trusted by older donors. Higher fees.

Recommendation: Start with Tithe.ly for ease. Graduate to Stripe for lower fees at scale.

7.3  YouTube Data API Implementation

To automatically load the latest video without a manual update each week:


Register for YouTube Data API v3 key (free, Google Cloud Console)


API call: GET https://www.googleapis.com/youtube/v3/search?channelId=CHANNEL_ID&order=date&type=video&maxResults=1&key=API_KEY


Extract videoId from response ? build embed URL


Cache result for 30 minutes to avoid rate limits


For live detection: check snippet.liveBroadcastContent === &quot;live&quot;



7.4  CMS Management

???  Weekly Video Update Workflow (No Code Required)

1. Staff logs into church website CMS

2. Navigate to: Settings ? Video ? Featured Video

3. Paste YouTube video ID or URL into the field

4. Save — video auto-embeds on homepage and /live page

5. Clear the field to return to auto-latest-video logic

Note: This field should be clearly labeled and take less than 30 seconds to update
